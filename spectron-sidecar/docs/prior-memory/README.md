# Prior memory (Ultima IV–VI)

Third-person notes of what the Avatar already knows of Britannia **before** Black Gate (“The Avatar remembered…”, “companions walked with the Avatar”). Written that way as a workaround so Surrealist chat is less likely to answer *as* the Avatar; first- and second-person memoir both tended to lock speaker POV. The sidecar’s inner-voice panels still use a separate first-person `/chat` prompt.

Deliberately do **not** name later-age factions here — shocks such as Skara Brae's ruin and any new creed should arrive only through play.
