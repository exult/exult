# Exult configuration keys, as shown by the Advanced tab of the themed
# Options window (gumps/Mui_config_meta.cc and gumps/Mui_config_editor.cc).
#
# One row per key:
#   path|type|default|range-or-choices|apply|description
#
#   path         full key path in exult.cfg. '*' stands for one dynamic part
#                of the path: a whole segment (config/disk/game/*/path) or
#                the end of one (config/audio/midi/volume_*). An exact path
#                wins over a pattern; of two patterns the longer one wins.
#   type         bool | enum | int | float | path | string. bool keys hold
#                yes or no.
#   default      the value Exult uses when the key is missing, exactly as
#                the code has it (empty: no fixed default, e.g. it depends on
#                the platform or on another key; the description says so).
#   range-or-choices
#                enum: comma-separated choices, matched without regard to
#                case. int and float: min..max (optional).
#   apply        now     = the Advanced tab applies the change at once
#                restart = only read at startup (or when that part of the
#                          engine starts again); takes effect after a
#                          restart.
#   description  one line in Australian English.
#                A description starting with "Old " marks a legacy key that
#                Exult converts at startup; the editor lists it only when
#                it is present.
#
# Kept in step with the code by tools/mui/scan_config_keys.py: --update adds
# keys found in the code with a TODO description, --check fails while a key
# in the code has no row or a row is still TODO. Descriptions are written by
# hand from the code that uses each key. Keys with no row (mods, Exult
# Studio, typing errors) are shown under "Other" and kept as they are.

# --- Disk and game folders ---------------------------------------------------
config/disk/data_path|path|||restart|Folder with Exult's own data files (exult.flx and friends). Empty means the folder chosen when Exult was built or installed.
config/disk/music_path|path|||restart|Folder with the digital music (OGG) files. Empty means the music folder inside the data folder.
config/disk/no_crc|bool|no||restart|Skip the checksum test of exult.flx, exult_bg.flx and exult_si.flx at startup (as the --nocrc option does).
config/disk/save_compression_level|int|1|0..2|restart|Compression of saved games: 0 none, 1 normal, 2 best. Other values are reset to 1.
config/disk/u7path|path|./blackgate||restart|Old single-game data folder. Converted to config/disk/game/blackgate/path at startup and then removed.
config/disk/game/*/path|path|||restart|Folder holding this game's original data. Default: a folder named after the game in Exult's game home folder.
config/disk/game/*/static_path|path|||restart|Folder with this game's STATIC files. Empty means the static folder inside the game folder.
config/disk/game/*/gamedat_path|path|||restart|Folder for this game's working GAMEDAT files. Empty means a gamedat folder in the user's save folder.
config/disk/game/*/savegame_path|path|||restart|Folder where this game's saved games are kept. Empty means the user's Exult save folder.
config/disk/game/*/mods|path|||restart|Folder searched for this game's mods. Empty means the mods folder inside the game folder.
config/disk/game/*/patch|path|||restart|Folder whose files override this game's data (the PATCH folder). Empty means the patch folder inside the game folder.
config/disk/game/*/source|path|||restart|Folder with this game's source files for Exult Studio. Empty means the source folder inside the game folder.
config/disk/game/*/codepage|string|ASCII||restart|Character set of this game's text. ASCII is the original 7-bit set.
config/disk/game/*/editing|bool|no||restart|Mark this game as being edited in Exult Studio.
config/disk/game/*/keys|path|(default)||restart|Key bindings file for this game. (default) uses Exult's built-in bindings.
config/disk/game/*/autonotes|path|(default)||restart|Automatic notes text file for this game's notebook. (default) uses the built-in notes.
config/disk/game/*/waves|string|---||restart|Digital sound effects pack for this game (a file in the data folder). --- lets Exult pick one that is installed.
config/disk/game/*/language|enum||en,fr,de,es,|restart|Language of this game's text when config/gameplay/language is not set. Empty keeps the game's own language.
